The watches

Three input profiles, one rule

Every action is reachable in every profile. Touch is an extra on top of the buttons, never the only route: a five-button watch must work with touch switched off. The app only uses Garmin's behaviours (select, back, next/previous page, menu), so the same code serves all of them. Where MENU does not exist, Garmin's action menu indicator (setActionMenuIndicator + onActionMenu) takes its place.

Decisions

Taken

  • scope products: every product in app/manifest.xml, listed per column in the watch table. Connect IQ 5.1 and up since 2026-10-23: the Descent Mk3 and Mk3i run 5.1 and the app uses nothing newer (it builds clean against their API lists).
  • layoutComputed from the Dc, not constants per family.
  • confirmNative WatchUi.Confirmation stays; on touch that is one tap on Yes, as on the touch fēnix today.
  • M1One hero number font per watch: NUMBER_MEDIUM where the Charging worst case fits (); NUMBER_MILD where MEDIUM overflows that stack (). Never NUMBER_HOT.
  • M2Focus pill width 212·s (0.815 of the width) plus the outline check.
  • M3Venu X1 uses the full rectangle: same vertical stack, rectangle widths, bezel parts follow the edge.
  • M4Find my car START: the map when parked and the watch has MapView; otherwise the Find my car list (). Find my car
  • M5On watches without MENU, turn the indicator on in every view that has an action list (Status, Charging, Find my car, Map preview, all Onboarding states): onActionMenu only fires with it on.
  • M6Target temperature becomes a list on every watch, like the charge limit. Target temperature
  • M7Button-neutral empty-state copy on every watch: "Refresh from the menu", "Try again from the menu".
  • M8No left swipe for the menu on profile B (): hold BACK is that platform's route.
  • M9Menu glyph at BACK on profile B, only where MENU is the only route (Onboarding).
  • M10No glyph drawn on the map (Garmin's view).
  • M11Page dots on the X1 keep the arc formula: a near-vertical column at the left edge, like Garmin's own indicator there.
  • M12Lock grid: chip width fits the longest label, capped by the width of the paired rows. Where three rows do not fit above the age, the spacing squeezes in order: word to grid 9 → 4, row gap 2 → 1, age clearance 3 → 1; only if that is not enough, two rows and "+N" (per column: "Lock grid" in the watch table). The indicator's keep-out limits only the right edge, so the grid may shift left and "Windows" fits next to it. Open items sort first, so an open door or trunk is never behind "+N".
  • M13Navigate is hidden where saveWaypoint is unavailable, checked at run time (the Venu 3S lists it only partly in its api.debug.xml). Still to try on a real Venu 3S.

Open, with the proposal shown on this page

  • M14Large user font sizes (up to 1.4× on ) and long copy: content keeps its order and gives way instead of overlapping. Onboarding text that runs past the outline in FONT_XTINY splits into parts with page dots, instead of the "…" the app cuts it with today (at the default size too where "Onboarding text cut" in the watch table says so); detail lines that would reach the age drop, last first; the lock grid goes to one row with "+N" and a small hero word; message screens wrap; home drops its chips, then the number (the ring shows the SoC); list rows grow to FONT_SMALL + FONT_XTINY + 8.
  • AMOLEDKeep 0x55FFAA as the accent, or use the brand's #78FAAE where the panel can show it.

M numbers are this page's; D1 to D7 in ui-improvements.md are the Night Panel's.

How it is drawn. Today's column runs the Night Panel code of tools/ui/poc/ unchanged (with the few as-built corrections each card names). The other columns use the same drawing calls in logical units (a frame 260 wide scaled by s), with each watch's fonts from its SDK device files (tools/ui/devices/11-devdata.js): heights and every character's advance, so wrapping and fitting match the watch. Text is drawn with Google's Roboto and Yantramanav, the fonts those watches use. Garmin's own parts (confirmation, toast, action menu indicator) are stand-ins on the AMOLED watches.
