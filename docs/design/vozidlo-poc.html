What changes

  • One accent colour: Škoda green. Electric Green (#78FAAE on skoda-auto.com, #55FFAA on the watch's 64-colour screen) for titles, focus and progress. Amber only for warnings, always with "!". Red only for failures. No orange.
  • One hero value per screen, at the widest part of the circle. Digits and % in the number font, words in a text font, so no screen relies on glyphs the number font lacks.
  • Status as chips. Closed things are outline chips with a check; things that need attention are amber chips ("! Plug in", "! Trunk").
  • No text hints. The bottom hint lines are gone. Where a button does something you cannot guess, a short arc or glyph sits next to that button.
  • Everything fits the circle. Every proposal text line is checked against the width of the circle at its height. Dynamic text is cut with "…" or wrapped.
  • Charging is reachable again. Home gets a Charging tile (grid) or row (list), so it no longer depends on a swipe.
  • Focus survives. After a command the focus stays on the tile you used. The grid scrolls under a fixed band and never covers it.
  • Plain labels. Sentence case, no raw API values ("Plugged in", not READY_FOR_CHARGING), one age format ("12 min ago").

Checked on the watch: on home, UP and DOWN move the tile focus. The hint "UP charging - DOWN status" is wrong. So today Charging detail, charge limit, mode and profiles cannot be reached with buttons; only an unconfirmed swipe down might get there.

Open decisions, shown as variants

  • D1Home: grid with fixes, or hero value with an action list. Home
  • D2Charging: its own view, or a page inside the Status loop. Charging
  • D4START on Status: refresh directly, or open an action menu. Status
  • D7Page indicator: Garmin's own arc, or dots. Status

Still to check on the watch

  • What the number font draws for letters it does not have.
  • Whether a single tap runs a tile.

Try it

Click the buttons on the bezel; hold UP for MENU. After clicking the area you can also use the arrow keys, Enter, Esc and M. Drag up or down on a screen to swipe.

How it is drawn. Each screen of today is a JavaScript port of the view's onUpdate() at 3c4d005, with the same coordinates and colours. The proposal uses the same drawing calls. Every character sits on the advance width of the fēnix 7 Pro font files from the Connect IQ SDK, so line lengths, wrapping and clipping match the device. Every proposal text line is checked against the circle by an automated fit check.

Source. The proposal and the fix ids (A1 to A23, C1a to C8) are in docs/design/ui-improvements.md. The board of today's screens alone is docs/design/vozidlo-screens.html.
